# Wikimedia Commons Art Catalogue — The Little Soldier

Verified public domain artwork from Wikimedia Commons for the Italian Campaign 1796-97 game. Each entry includes confirmed URLs, artist, license, and game chapter mapping.

**Research date**: 2026-03-15
**Method**: Wikipedia API + Wikimedia Commons API queries with metadata extraction

---

## How to Use This Catalogue

- **Commons page URL** = the file description page with full metadata and license
- **Direct image URL** = the actual image file (for preview; right-click to download from Commons page)
- **License**: "Public domain" means unrestricted use. "CC BY-SA" requires attribution and share-alike.
- Entries marked **HIGH** usefulness are directly relevant to specific game chapters/phases.
